# KioskPay www — design

## Intent

Marketing homepage for **KioskPay** (payments front door powered by Malipo). Visual DNA from [Ignyte](https://www.ignyte.ae) — soft gray, pale yellow beams, spaced wordmark, ghost/fill CTAs, grayscale astronaut — amplified into Kenya-kinetic craft: STK light, till drama, scroll reveals.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | `#bfc3c7` | Page / hero ground |
| `--yellow` | `#fef27f` | Fill CTAs, beams, STK accents |
| `--mpesa` | `#0f6b68` | Till labels, verified chip |
| `--ink` | `#0a0a0a` | Text, ghost borders |
| `--radius-btn` | `6px` | Buttons |
| Font | Sora Variable | Display + body |
| Motion | `--ease-out` / `--dur*` | Entrances + idle |

## First viewport

1. Absolute nav — spaced wordmark, Log In / Join Now / animated menu
2. Kinetic headline (italic second line) over breathing yellow beams
3. Supporting line + CTAs
4. Floating astronaut + STK ping rings

## Sections

Intro (photo + caption chip) → rail strip → destination till stage → live STK phone → closer → manifesto audience list → split FAQ → footer join banner
