# KioskPay (malipo/www)

Public marketing homepage for **KioskPay**, the payments front door powered by Malipo.

Visual language is pinned to [Ignyte](https://www.ignyte.ae): pale yellow geometry, spaced wordmark, ghost/fill CTAs, full-bleed hero photography on a soft gray ground.

## Develop

```bash
cd malipo/www
npm install
npm run dev
```

## Stack

- Astro 7
- Plain CSS (no Tailwind)
- Sora for display and body
